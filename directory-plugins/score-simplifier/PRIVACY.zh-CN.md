# score-simplifier 数据处理说明

[English](PRIVACY.md)

本包没有开发者运营的后端、账户数据库或包内遥测。用户选择的 AI 宿主按自身条款和设置处理对话与提供的材料。本说明针对包内代码，不承诺宿主如何保留提示词或处理账户。

**输入：**已获授权的输入乐谱与明确改编要求；新版本乐谱输出和 QA 记录。

**本地保存：**文件位于用户指定工作区或宿主执行环境，包内代码不会将其发送给发布者。本地记录保留到用户删除；宿主或云端记录遵循宿主的保留控制。下载文件是导出，不证明持久保存。

**联网：**宿主可能在用户要求时查询公开来源。Reflection 的可选目录刷新和明确升级工具访问 GitHub；Score 明确准备 schema 时下载经哈希锁定的 W3C 文件。这些工具不发送职业材料、个人回答或曲谱内容。插件不配置后台刷新、自动升级或外发消息。只有明确执行 Python 依赖安装时才访问包源。

**用户控制：**用户决定来源范围、保存、导出和外部动作。不要把私人简历、日记或乐谱附在公开 issue；反馈时使用脱敏或虚构示例。发布者在送审前另行确认可联系的审核邮箱及面向年龄范围。
