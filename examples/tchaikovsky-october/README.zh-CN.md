## 每档改变什么

三档都保留右手主旋律和第 9–14 小节左手主题回应的音高、起音及延音时值，同时保留原调、拍号、旋律中的半音、三连音和 16 小节路线。这些保护项已与本次有限范围的转录核对，不代表对所有版本的认证。

- **L1 核心版：**去掉右手内声部填充，减少保持和弦音，并将左手支撑重配到七半音以内。旋律与回应仍在；代价是和声丰满度与原低音音区的损失。旋律八度跳跃和三连音读谱仍需处理。
- **L2 易弹音乐版：**保留更多和声及内声部色彩，去掉部分重复音，将较宽的左手音重配到九半音以内。它仍比 L1 活跃；按音高质心代理量，一些左手位置变化接近 16.33 半音。声部突出与双手协调对具体演奏者是否合适，尚未确定。
- **L3 中级简化版：**保留 253 个有时值书面音中的 252 个，重配宽跨度左手低音并去掉一个冲突重复音。左手保持跨度从 17 降到 12 半音，展示了极少删音也能通过音区改变减轻负担。但八度跨度、多声部平衡和较大的左手移动仍在。

三档均省略 **5 个倚音**，并把 **2 个滚奏和弦、共 4 个谱表琶音记号**改为同时起音。装饰音执行负担下降，表现性的起音也因此改变。这是明确的音乐损失，不能声称全部特点都保留。参考版与三档均不复制来源指法和踏板标记，部分连线／方向标记的附着位置属于解释性决定。参考版保留 5 个倚音及 4 个滚奏记号。

[完整指标](METRICS.json)依据书面保持时值和明确的谱表到左右手映射。Original 的比較投影排除倚音时长和滚奏起音偏移，不构成完整原版播放核验。踏板不会自动缩短书面保持时值。质心变化只是几何代理量，不是指法或真实手位移动结论。假设速度下四版最大起音组密度均为每秒 3 组，因此音数减少不意味着所有负担都下降。

## QA 状态

[汇总](QA.json)：四份 MusicXML 均通过 schema 验证，所有最终乐谱页均由 agent 看图检查；受保护的有时值声部在各版一致。来源保真仅表示 agent 与指定 Schirmer 页的有限范围核对，未进行人工来源审核或校勘版认证。

L1/L2/L3 的时间线、难度阈值、双手冲突与序列化 MIDI 读回检查通过，但音乐性验收仍为 **REVIEW_REQUIRED**。内部 MIDI 核对了已表示音符的音高与时点，力度统一，不含表现性踏板、力度和自由速度。

Original 保留倚音／滚奏记谱，但没有已接受的实现提案，内部播放核验为 **INCOMPLETE**。单独提供的 MuseScore MIDI 只作**未完整核验的试听参考**，不作为记谱或播放权威。所有版本的人工试听、实弹、音乐性验收与教学等级校准均为 **NOT_RUN**。技术检查不能证明 L1 适合初学者，也不能证明任何一版适合某个具体手型。
