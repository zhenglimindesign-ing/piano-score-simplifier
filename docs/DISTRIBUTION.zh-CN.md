# 分发内容与发布状态

[English](DISTRIBUTION.en.md) · [宿主证据](SUPPORT.zh-CN.md)

`DISTRIBUTION.json` 是不可变的 **CONTENT_SNAPSHOT**：记录实现版本、明确的公开文件清单、字节数、SHA-256 和清单摘要。它描述当前列出的内容，不表示是否已经发布或验收。任何清单文件改变都必须重新生成；不能保留过期哈希或错误的“尚未公开”声明。

`PUBLICATION.json` 是远端核对完成后单独写入的回执，记录公开仓库、不可变 release/tag 提交、资产及核验哈希。回执与清单 JSON 自身均不列入内容哈希清单，回执也不进入 source ZIP，避免循环哈希和发布后改包。release 标签之后可以增加一个仅含回执的 main 提交，而不改变任何清单字节；标签与上传资产保持不变。release 中的 manifest 与标签根目录 manifest 字节一致。

便携 ZIP 仅包含完整的兼容 skill 目录和项目 LICENSE/NOTICE。源码 ZIP 包含明确允许公开的代码、双语说明、《十月》公开样例及 manifest；不包含私有扫描、仓库历史、验收日志、凭据或其他本地输出。《十月》参考版为重新转录／渲染，附权利与内嵌字体通知。该流程保留独立的私有维护仓库，不修改已有 release 资产。

哈希有效证明内容一致，不证明真人可弹、音乐性验收、考级校准或所有宿主全面支持。请以每个样例 QA 和具体宿主路径证据为准。
