# PDF 预检、交付与阶段预算

处理 PDF 来源、图像交付或阶段预算检查点时阅读本参考。辅助程序只做只读检查，不包含 OMR，也不是自动 PDF 编配器。

## 输入预检

```sh
python scripts/preflight.py --input SOURCE.pdf --score-kind voice_piano --delivery reduced_pdf
```

参数由 agent 根据来源和请求选择，用户不必学习。程序报告来源 SHA256、页数和最多三张代表页的信息。图像资源和提取文字只提示可能属于扫描谱，不证明可读性、谱表角色或音符正确。用当前本地 PDF 工具渲染并查看代表页，确认角色与受保护内容。`voice_piano` 声明要求保留人声和歌词，但不代表自动完成转录。

全量处理前，内部核对一个连贯乐句的旋律、低音、变音、休止、延音与连音组。OMR 结果在记谱和原谱对照一致前只是候选。抽样不足以支持可靠记谱时，定位失败点，在请求范围内选择有来源映射的逐段判读／图像路线；确需改范围时再给具体方案。内部抽样后可以完成整份交付，无须等待朋友先试弹。

当前核心接受一个钢琴 MusicXML part。包含人声、其他乐器或复杂记谱的 PDF，需要单独建立来源准备与映射；元数据预检不能证明已支持这些声部的自动编配。

## 交付约定

| ID | 页面实际效果 | 可编辑谱与回放 |
|---|---|---|
| `annotated_pdf` | 保留原音符，加省音标记 | 不承诺完整可编辑谱；可附诊断样段 |
| `reduced_pdf` | 实际擦除指定符号，按完整乐谱行重新分页 | 不承诺完整可编辑谱；可附诊断样段 |
| `editable_score` | 从规范记谱重新刻谱，省音删除或改为休止 | 声明的全曲／乐句范围内，交付完整 MusicXML 和核对过的 MIDI |

请求结果有歧义时，用同一个原谱乐句解释差异。用户选择已清楚时，不必制作三套演示。保留扫描原件和旧版本。样段文件标明实际页／行／小节，以及未加入的声部或演奏特征。图像减音 PDF 可用于练习，但不证明 L3 已校准或完整记谱语义已转录。

## 局部图像删音记录检查

擦除符号前，先对照原谱核对受影响内容，再整理实际音头、延音端点和变音继承记录。`--pdf-edit-records RECORD.json` 将检查绑定到原始 `--input` 哈希。它检查共用印刷音头被当作独立省音、遗留／错误延音线，以及缺失的变音记号转移；不读取原始 OMR，也不修复像素。

最小记录结构：

```json
{
  "source_sha256": "SHA256 of original PDF",
  "heads": [{"id": "h1", "page": 1, "bounds": [10, 20, 12, 8], "pitch": 60}],
  "edits": [{"id": "h1"}],
  "ties": [],
  "removed_tie_ids": [],
  "accidental_dependencies": [],
  "accidental_transfers": []
}
```

`bounds` 为同一页面图像坐标中的 `[x, y, width, height]`。交并比 >= 0.8 的重叠音头必须经原谱核对并合并为一个实际音头记录，不能为重复识别多写一枚休止。延音线有 `id`、`start`、`stop`；根据印刷曲线核对音高和端点。变音依赖／转移有 `from`、`to`、`sign`。记录检查只覆盖提供的记录，来源保真与音乐认可仍为 `NOT_RUN`。

## 阶段预算

```sh
python scripts/preflight.py --budget-state work/stage.json
```

```json
{
  "stage": "pdf_probe",
  "observed": {"elapsed_minutes": 8, "input_tokens": 50000, "cached_input_tokens": 40000, "output_tokens": 2000},
  "limits": {"elapsed_minutes": 20, "uncached_input_plus_output_tokens": 50000},
  "repair_attempts": 1,
  "gate_status": "FAIL"
}
```

从可获取的运行证据记录阶段增量；累计计数先减去起点快照。计数重置或数据缺失时保持未知。`input_tokens` 包含缓存输入。程序计算非缓存输入加输出；推理输出已包含在输出中。该数值不是账户额度用量，也不是货币价格。经过时间不等于有效人工工时。可复用的部署／开发与每首都需要的制作工作分开记录。

`pdf_probe` 默认经过时间检查点为 20 分钟；其他阶段没有隐含时间上限。Token 限额可选且必须明确声明。达到检查点，或同一检查经过两次修复仍失败，返回 `REPLAN_METHOD`：保留最佳候选，停止重复该方法，定位问题，继续独立且已授权的工作。修复通过后不会仅因已经尝试两次而受阻。改变交付、音乐身份、付费基础设施或实质增加成本，需要具体用户决定；普通实现路线调整无须反复许可。

预检退出码：0 只表示只读检查完成，不是乐谱验收；1 为输入／记录错误；2 为图像记录检查失败；3 为阶段预算要求调整方法。MusicXML 流水线也接受 `--budget-state`，在创建输出目录前拒绝预算已耗尽的运行。这些辅助程序不监控或改变账户计费。

## 验收证据

分别记录来源／记谱复核、MIDI 事件比对、引擎读回、音频数据检查、实际音频分析与真人试听／试弹。没有音频分析通道就不能声称 agent 已听过。未发生的体验检查保持 `NOT_RUN`。尽早检查连音组休止与共键持续音；引擎奏法差异要明确记录，不能据此悄悄放宽记谱检查。
