# Score Simplifier · 钢琴谱简化

[English](README.md)

[下载实验版](https://github.com/zhenglimindesign-ing/piano-score-simplifier/releases/tag/v0.3.6) · [安装说明](docs/INSTALL.zh-CN.md) · [反馈问题](https://github.com/zhenglimindesign-ing/piano-score-simplifier/issues)

**先弹喜欢的音乐，再逐步接近原版。**

喜欢一首曲子，却被原谱的和弦、跳跃或复杂伴奏挡住？Score Simplifier 是一个 AI skill：它从可靠原谱出发，制作更容易演奏的钢琴独奏版本，并允许你在实际练习后继续调整。

目标不只是“删掉一些音符”，而是降低**真实的演奏负担**，同时尽量保留这首曲子的音乐身份。

**支持范围：钢琴独奏曲谱。** 可使用公版、自创或已获相应授权的乐谱；曲目不限于固定清单。

## 为什么是 Score Simplifier？

### 音符变少，不一定真的更容易

一份看起来很稀疏的谱，仍可能有够不到的跨度、很大的跳跃，或者别扭的双手协调。

Score Simplifier 会把不同技术负担分开看，例如：

- 单手同时需要按住的跨度和音数；
- 连续手位移动与大跳；
- 左右手之间的冲突；
- 起音密度与双手协调；
- 多声部与旋律突出要求。

只有**真实演奏负担确实降低**，才算有效的简化。

### 不会把所有作品都压成“旋律 + 和弦”

有些内声部虽然不是主旋律，却承担了重要的和声、声部进行或作品气质。

编配时会区分：

- 应优先保护的主旋律、标志性节奏和关键低音；
- 对作品身份重要的内声部与和声色彩；
- 可以压缩的和弦填充；
- 可以优先减少的重复音、八度或技术成本很高的材料。

浪漫派抒情曲、巴赫复调和琶音型作品，不应该套同一套“删音公式”。

### 成功导出 PDF，不等于改编已经成功

来源保真、技术难度、谱面排版、播放正确和真人可弹性，是几件不同的事。

这个 skill 会把这些检查分开处理；没有实际完成的检查，不会悄悄当成已经通过。

## 选择适合这次练习的档位

| 档位 | 改编重点 | 什么时候选 |
|---|---|---|
| **L1 · 核心版** | 突出旋律，保留基本和声支撑，明显减轻织体负担 | 想先完整地奏出音乐主线 |
| **L2 · 易弹音乐版** | 保留旋律、主要和声和精选的特色织体，减少难以执行的伴奏 | 希望保留更多原曲感觉；默认从这一档开始 |
| **L3 · 中级简化版** | 保留更多声部与细节，集中调整较难的技巧段落 | 已有一定基础，希望更接近原谱 |

档位描述的是改编取向，不对应官方考级。不同曲目的难点并不相同；先试一个小样，比只看等级名称更容易判断是否合适。

## 需要先告诉它“我是什么水平”吗？

**不需要填写能力问卷，也不要求你有考级。**

如果希望第一版更贴近自己，可以选择提供：

- 当前大致水平，或最近能比较舒服弹完的曲子；
- 手能舒服覆盖的跨度；
- 八度、和弦、大跳、三连音、多声部里，哪些对你特别难；
- 某个具体位置为什么弹不下来。

“英皇几级”或“学了几年”只是一种软参考。**具体的身体／技术限制和真实试弹反馈，比等级标签更重要。**

没有这些信息也不影响开始：skill 可以先从通用档位生成，再根据你的实际试弹继续调整。

## 选一个短版本，还是整首？

| 篇幅 | 得到什么 | 适合做什么 |
|---|---|---|
| **Mini · 乐句版** | 一个完整的音乐想法，有自然的起点和结尾；通常约半页到一页 | 先试难度和改编方向 |
| **Full · 完整版** | 保留主要段落与曲式路线；若有删节，会在说明中列出 | 用一个连贯版本练习整首 |

页数服从乐句完整和谱面可读性。Mini 通过选段和编配控制篇幅，而不是缩小谱面来“凑页数”。

## 原谱从哪里来？

一份可靠的简化谱，首先要知道**到底在简化哪一份原作**。

skill 可以从这些来源开始：

1. **你提供的谱**
   - MusicXML / MXL 是优先的结构化输入；
   - 清晰 PDF 也可以，但需要先转录并和原谱核对。

2. **可靠的 Public Domain 原谱**
   - 如果你只提供曲名，而且当前运行环境可以联网，agent 可以先寻找可靠的公版或其他允许使用的版本；
   - 在使用依据允许时，优先考虑 Urtext／学术版、初版扫描或来源清楚的历史版本。

3. **开放授权或可靠的数字乐谱资料**
   - 可以作为结构化输入或交叉核对来源；
   - 机器可读不等于权威，如果资料冲突，以已经核实的原谱为准。

来源或音符无法确认时，不会凭记忆补齐。

## 第一次使用

当前已经验证过的路径包括 **Codex 本地、Claude Code、Claude 网页和 ChatGPT Work**，但每一种都有明确的测试边界。具体版本与支持范围见[安装说明](docs/INSTALL.zh-CN.md)。

以 Codex 本地使用为例：

1. 下载并解压 release 包。
2. 将完整的 `piano-score-reduction` 文件夹放入项目的 `.agents/skills/`。
3. 在 Codex 打开该项目，让它检查 Python、依赖和 MuseScore。
4. 提供曲谱；或者只提供曲名，让 agent 在可用环境中先查找允许使用的可靠来源。然后描述你希望怎样简化。

> **命名说明：** Score Simplifier 是公开项目名；当前 skill ID 和安装目录名仍是 `piano-score-reduction`。

例如：

~~~text
请使用已安装的 piano-score-reduction 曲谱简化 skill。
把我提供的曲谱做成 L2 易弹音乐版，先生成一个 Mini 乐句版。
保留主旋律和原曲的感觉，让伴奏少一些跳跃。
请给我 PDF、MusicXML、MIDI，并说明主要改动和仍需注意的难点。
~~~

拿不准档位时，可以只说“先做一个更容易的短版本”。

## 你会收到什么

| 内容 | 用法 |
|---|---|
| **PDF** | 看谱、打印和练习 |
| **MusicXML** | 在制谱软件中继续编辑 |
| **MIDI** | 试听音符、节奏和版本差异 |
| **可选音频** | 环境允许时，方便直接试听 |
| **改编说明 / QA** | 查看保留了什么、调整了什么、哪些地方仍难、哪些检查尚未完成 |

先看谱、听一遍，再按适合自己的速度试弹。MIDI 是试听参考，实际弹奏感受才决定这份改编是否真的适合你。

## 练起来还不合适？继续改

告诉它具体小节和困难，例如：

> 第 8–12 小节的伴奏还是跳得太远。请保留旋律，让伴奏更稳，保存一个新版本，并保留上一版供我比较。

也可以要求保留某个伴奏型、减小和弦跨度，或在认可 Mini 后继续 Full。原始曲谱和已有版本会保留。

## 使用边界与反馈

简化会改变部分伴奏、音区或织体，改编说明会列出主要取舍。若某段无法兼顾音乐特点与目标难度，应明确说明冲突，而不是悄悄牺牲重要音乐信息。

不清晰的照片和部分复杂记谱可能需要额外转录或处理。明确弱起、普通整小节反复与一二房子已有播放顺序检查；部分单倚音、波音和单手 2–4 音滚奏可以按明确提案处理。复杂反复导航、更多装饰音和其他复杂记谱可能保持未完成状态，并明确报告。

成功生成 PDF 不代表播放、来源保真或音乐性已经完整核验。L1–L3 是编配目标，不是官方考级，也不保证适合所有人的手型和技术背景。

反馈时，给出所用版本、具体小节，以及“哪里仍难”或“哪里失去了原曲感觉”。遇到运行问题，附实际错误信息。
